# 🧠 Mental Health Detection using NLP & Deep Learning

An intelligent NLP-based web application that analyzes user text and predicts mental health related conditions using Deep Learning models. The project combines Natural Language Processing techniques with an interactive Gradio interface for real-time predictions.

---

# 🚀 Project Highlights

✅ NLP-based text classification  
✅ Deep Learning prediction system  
✅ Interactive Gradio web application  
✅ Text preprocessing and tokenization  
✅ Real-time mental health prediction  
✅ User-friendly interface  

---

# 📌 Overview

Mental health analysis through text data has become an important application of Artificial Intelligence and Natural Language Processing. This project processes textual input, applies NLP preprocessing techniques, and uses trained Deep Learning models to classify mental health related content.

The application is deployed through a Gradio interface where users can enter text and receive instant predictions.
